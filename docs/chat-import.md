# 日报导入使用说明

## 安装与入口

安装或覆盖升级最新版 `DayLog.apk`，先添加团队成员，然后打开“数据 → 从微信导入日报”。覆盖安装同签名版本会保留原有数据；不要先卸载旧版。

## 从微信提取

1. 填写与微信聊天页面顶部一致的群聊名称，选择开始和结束日期、时间。
2. 阅读并勾选本次屏幕读取授权，点击开启，在系统无障碍设置中开启“日报导入屏幕读取”。部分手机需要先在应用信息页允许受限设置。
3. 点击打开微信，手动进入目标群。建议先在微信中查找聊天记录，按日期定位到结束时间附近，再进入原聊天页面。
4. 在底部控制条点“开始 / 继续提取”。软件只在目标群聊天页读取可见文字，并向更早的消息翻页。可点“停止并审核”随时返回。
5. 返回后逐条打开卡片，核对微信昵称、正文和发送时间，选择团队成员后点“是，导入日报”。不属于日报则点“不是，删除此条”。
6. 同群同昵称再次选择成员时，会出现“上次该昵称为 XXX”。只有成功确认导入才更新记录。
7. 最后一条处理完自动回首页；中途退出会二次确认，确认后清空未处理内容并返回上一级。已导入的日报保留，微信原消息不变。

## 识别规则

消息正文从第一个字符开始，必须是 1–2 位数字 + 1 个标点 + 1–2 位数字；前一项为 1–12，后一项为 1–31。支持全角数字及中文标点。

例如 `9.3 今日工作`、`09、03 日报`、`12/31 总结` 符合；`13.3`、`9.32`、`日报 9.3`、开头带空格或换行的不符合。只按此数字规则筛选候选，因此 `2.31` 也会进入人工审核。

## 使用边界

这是主动授权的屏幕读取流程，不是微信官方群聊历史接口。群聊由你在微信中手动选择，日期范围在本软件选择。界面结构及可读取内容会随微信、手机系统版本变化，不能保证读全所选范围。

只处理可读取的文字正文；图片、语音、撤回内容不提取。微信经常只显示相邻消息共用的时间标签，因此卡片中的时间是待核对的参考值；缺少昵称或时间时必须手动补充。不能把日报正文开头的“9.3”当作消息的发送日期。

翻页重叠内容会合并；完全相同且没有可区分时间的重复消息可能被合并，需要复核。每次最多读取 200 屏、约 6 分钟或 500 条候选，达到边界会说明原因，请缩小时间范围继续。

离开微信或目标群会暂停提取；返回后需再次点开始。待审核内容只在内存中保留，退出确认或进程结束会清空。关闭系统无障碍服务不会删除已提取候选，可返回软件审核或退出。

## 备用文本导入

屏幕无法读取时，可选择“粘贴聊天文本导入”。每条消息使用以下格式，正文可换行：

```
[2026-09-03 18:30:00] 微信昵称
9.3 今日工作内容
第二行正文

[2026-09-03 19:20:00] 另一昵称
9.3 工作总结
```

只提取符合开头规则且时间位于所选范围内的消息，仍需逐条审核。
